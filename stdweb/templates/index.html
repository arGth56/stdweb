STDWeb brings a full transient and photometry pipeline to your browser — for free. Upload FITS frames and run science-grade analysis: astrometry, Gaia-calibrated photometry (G/BP/RP), optional template subtraction, forced photometry, and simple transient detection, powered by STDPipe. No local install; used in production for alert follow-up (e.g. RAPAS / Observatoire de Bretagne Sud).

The service implements a self-consistent, mostly automatic workflow from STDPipe routines — one of the few places on the web where amateur and professional observers can get publication-quality calibrated magnitudes this quickly.

STDWeb is being developed by Sergey Karpov, and was originally created as part of GRANDMA project.

If you use STDWeb in your work, or use results from STDWeb in a publication, please cite

Karpov, S. (2025). STDweb: simple transient detection pipeline for the web. Acta Polytechnica, 65(1), 50-64.
https://doi.org/10.14311/AP.2025.65.0050

If you want to better understand the routines used for it, please consult STDPipe documentation and example notebooks, as well as the actual source code behind this web tool.
